# Колясочная

Демо-магазин детских колясок с ИИ-консультантом: Flutter-приложение и бэкенд на Go.

> Это демонстрационный проект. Цены и наличие условные, адрес и телефон магазина — заглушки.

## Что внутри

- **`app/`** — Flutter-приложение: каталог с поиском, фильтром по типу и сортировкой, карточка коляски, корзина с расчётом доставки, информация о магазине. Вкладка «Помощник» (чат с Claude) — в работе.
- **`backend/`** — Go (stdlib `net/http`), каталог из 27 колясок, REST API для приложения. Ключ Claude API хранится только на бэкенде.

## Архитектура приложения

Слоистая архитектура, повторяющая большой продакшн-проект, но в одном пакете:

```
app/lib/
  services/      Retrofit-сервисы и DTO (*Obj) с маппингом в доменные модели
  objects/       доменные модели (freezed)
  repositories/  репозитории: guardApiCall, ретраи, типизированные ошибки
  core/          BaseBloc, навигатор на Navigator 2.0 pages, MessageBus, тосты
  di/            injectable + get_it
  ui_kit/        дизайн-токены и общие виджеты
  features/      фичи: bloc / models (VM) / mappers / widgets / screen / pages
```

- Стейт-менеджмент — BLoC (`flutter_bloc`), события и состояния на freezed sealed-классах.
- Навигация, тосты и межфичевые сообщения — только в обработчиках BLoC; виджеты лишь отправляют события.
- Данные из API превращаются в доменные модели в DTO (`Transformable`), а в VM для экрана — в мапперах.
- Правила кода для Claude Code лежат в [`.claude/rules/`](.claude/rules), обзор — в [`CLAUDE.md`](CLAUDE.md).

## Запуск

Бэкенд:

```bash
cd backend && go run ./cmd/server
```

Приложение (нужен [FVM](https://fvm.app)):

```bash
cd app
fvm install
fvm flutter pub get
fvm flutter run --dart-define=API_BASE_URL=http://localhost:8080
```

Для Android-эмулятора адрес бэкенда — `http://10.0.2.2:8080`. В web-сборке фото колясок не грузятся: сайты производителей не отдают CORS-заголовки.

## Использование ИИ

Проект написан с помощью Claude Code (Anthropic): код, правила и документация создавались в диалоге с моделью, архитектурные решения и ревью — мои.

## Фото и характеристики

Фотографии и характеристики колясок принадлежат производителям (Cybex, Bugaboo, Joolz, Stokke, Inglesina и др.) и подгружаются с их сайтов по ссылкам из каталога; в репозитории они не хранятся.
